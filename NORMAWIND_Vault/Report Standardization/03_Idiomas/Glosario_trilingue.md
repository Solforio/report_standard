# Glosario trilingüe (ES · EN · CA)

Usar **siempre** estos términos. ✔ = confirmado en informes históricos NORMAWIND · (¿) = propuesta pendiente de validar por el equipo.
Si falta un término, añadirlo aquí (ver [[Ampliar_el_sistema]]).

## Nombres propios que no se traducen
NORMAWIND, WindPRO, WAsP, EMD, Vestas, Siemens Gamesa, GE Vernova, Suzlon, OMIE/OMIP, ETRS89, IEC, nombres de organismos y expedientes. Nombres de normas: se mantiene el original (*Decret-llei 16/2019*) y, si el informe es en otro idioma, se añade traducción orientativa entre paréntesis la primera vez.
